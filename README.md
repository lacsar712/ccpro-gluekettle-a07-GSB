# GlueKettle-01 · 骨巷熬胶坊

一排熬锅作业台。登录后顶栏分两页：**锅位作业台**（横向锅位，点锅登记煮胶峰值并改状态）与**押印台**（按锅筛押印名单、加印、撤印、主管交本）。前端是原生 JS，没有 React/Vue/Svelte。

## 技术栈

| 层 | 技术 |
| --- | --- |
| Web API | Starlette 路由表（不是 FastAPI Depends） |
| 结构 | SQLModel 实体 + `domain.py` 门槛 |
| 数据 | SQLModel / SQLAlchemy · psycopg2 · PostgreSQL 15 |
| 前端 | 原生 ES Module · Vite 仅打包 |
| 部署 | Docker Compose |

## 路径与端口

- 前端：http://localhost:4920
- API：http://localhost:8920
- PostgreSQL：localhost:6320

## 演示账号

`admin` / `123456`（管理员，可撤印、交本），`worker`、`worker2` / `123456`（操作工，只能给自己加印）

## 业务规则

锅不可标「已出胶」，除非同时满足（规则在 `backend/app/domain.py`）：

1. 最近一次煮胶峰值 **≥ 90℃**；
2. 该锅**未撤回押印按人名去重后至少两名不同人**——空名单、单人、两人同名（重复行）一律挡住。

登记峰值、改成冷锅/熬煮中完全不触碰押印。

### 押印

- 押印行含：锅码、印人、加印时刻、撤回时刻（可空）。
- 操作工**只能给自己加印**（印人由服务端按登录身份落库）；**撤印归管理员**。
- 押印以「册」为单位：一锅至多一册在册（含未撤回押印）。管理员可整本一次交入两名以上不同人的押印；两名主管几乎同时抢交两本时，由数据库部分唯一索引仲裁，**库里只保留一套**，败者收到 409。
- 册内最后一枚押印被撤回时自动关册，该锅回到零押印。
